# ElecPad

<div align="center">

**ElecPad** は、ElectronとWeb技術をベースに開発された、モダンで軽量なVS Code風コーディング・メモ帳アプリです。

[特徴](#特徴) • [主要機能](#主要機能) • [インストール](#インストール) • [使い方](#使い方)

</div>

---

## 🛠 特徴

- **VS Code風の洗練されたUI**: Dark+テーマをベースにしたダークモード、等幅フォント、および使い慣れたレイアウト。
- **カスタムタイトルバー**: OS標準の枠をなくし、ミニマムでスタイリッシュな独自タイトルバーを実装（ドラッグ移動、省略表示対応）。
- **コーディングに最適化**: 行番号のリアルタイム同期、Tabキーによるインデント挿入、カーソル位置や文字数のステータス表示。
- **軽量・高速**: 余計な重い機能を省き、サクサク動くシンプルなエディタ体験を提供。

---

## 🚀 主要機能

- **ファイル操作**: 
  - 新規作成 (`New File`)
  - 既存ファイルの読み込み (`Open File...` / `Ctrl + O`)
  - 上書き・名前を付けて保存 (`Save` / `Ctrl + S`)
- **エディタ補助**: 
  - 行番号表示（Gutter）
  - 現在のカーソル位置（行・列）リアルタイムトラッキング
  - 未保存ファイルインジケーター (`●`)
- **ウィンドウコントロール**: 最小化・最大化・閉じるをカスタムボタンで操作

## 📦 デバッグ起動（改造版の起動など）

事前に [Node.js](https://nodejs.org/) がインストールされている環境で、以下のコマンドを実行してください。

```bash
# リポジトリのクローン
git clone [https://github.com/exfat-dev3/ElecPad.git](https://github.com/exfat-dev3/ElecPad.git)
cd ElecPad

# 依存パッケージのインストール
npm install

# アプリの起動
npm start
```
